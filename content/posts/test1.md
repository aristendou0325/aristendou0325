# 🧠 一、你现在这个系统的使用方式（最基础）

你现在已经有：

* `main.py`
* `codebase/`
* Ollama

---

## ✅ 日常使用流程（以后就这么用）

### 1️⃣ 打开终端

进入你的项目：

```bash id="d2q6q0"
cd D:\projects\my_ai_project
```

---

### 2️⃣ 启动 Ollama（如果没自动启动）

```bash id="a3p4xl"
ollama run llama3
```

（或者你用 `ollama serve`）

---

### 3️⃣ 运行你的 AI

```bash id="fkh8o7"
python main.py
```

---

### 4️⃣ 开始问问题

比如你写代码时：

```text id="u3r6vh"
你: quick_sort 这个函数可以优化吗？
```

```text id="mxv6kp"
你: 我代码里有没有重复逻辑？
```

```text id="6rrmrf"
你: 帮我基于已有代码写一个新函数
```

👉 它会用你的代码来回答

# ⚠️ 五、当前版本的限制（你要知道）

现在这个版本：

👉 ❌ 每次都会加载全部代码

所以：

* 代码一多 → 变慢
* 内容一多 → 不准
